
# Google Play Policy Deadlines Calendar

An unofficial calendar of upcoming Google Play policy changes and enforcement deadlines for Android developers.

Stay informed about important policy updates and prepare your Android apps before enforcement dates.

## 📅 Calendar

- **Format:** iCalendar (`.ics`)
- **Platforms:** iOS (Apple Calendar), Android (Google Calendar)
- **Events:** Individual policy deadlines
- **Reminders:** 7 days and 1 day before each deadline
- **Time zone:** All-day events

## 📱 Installation

### iOS — Apple Calendar

1. Download the `.ics` file.
2. Open it on your iPhone or Mac.
3. Import the events into Apple Calendar.
4. Verify that reminders are enabled.

### Android — Google Calendar

1. Download the `.ics` file.
2. Open [Google Calendar](https://calendar.google.com/) in a desktop browser.
3. Navigate to **Settings → Import & export**.
4. Select the downloaded `.ics` file.
5. Choose your calendar and click **Import**.
6. Events will sync to your Android device if calendar synchronization is enabled.

## 🔄 Updates

This calendar is maintained manually.

Importing an `.ics` file does not automatically synchronize future changes. Download and import updated versions when necessary, taking care to avoid duplicate events.
